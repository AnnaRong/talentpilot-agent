# TalentPilot v0.4 交付说明

日期：2026-09-21。此版本继续补齐 v0.3 的本地可运行链路，不代表所有 PRD 项目或生产合规已经完成。

## 新增可运行能力

1. **北森岗位读取**：调用已安装 Ego 浏览器，复用用户授权登录态，重新从门户进入岗位页；
   扫描虚拟列表、按岗位编号去重，声明数量与读取数量一致才返回。控制台同步展示岗位 HC，
   并读取当前账号可见的全部时间面试，按岗位、轮次、候选人去重展示一面/二面/三面人数。
   岗位 UUID 没有从岗位页取得时明确标记。
2. **申请只读采集**：锁定“百度社招实习生招聘流程 / 招聘中职位 / 全部简历”；
   通过页面点击翻页，观察本次页面自身发出的读取响应。不保存或重放签名 URL、不导出 Cookie。
   只提取申请 ID、候选人 ID/姓名、岗位编号/UUID、当前阶段/状态和时间。
   逐页校验总数、容量、数量、稳定 ID；失败时不提交部分数据为完整成功。
3. **面试列表采集**：读取当前账号的“全部时间面试”，保留场次综合结果、面试官个人结果、
   轮次、预约时间与申请关联。个人面评正文不在列表响应中，不能编造或复用旧正文充当新证据。
4. **协作任务**：新快照经过同一验证器后加密入库，自动提交统计/审计管线。新旧数据集独立留存。
5. **岗位面试官模板**：精确岗位+部门+轮次；负责人确认，乐观版本锁、修改历史；
   当前数据集所有申请自动匹配本地模板。此功能不向北森写入面试官安排。
6. **周期只读巡检**：SQLite 持久化计划、 due-slot 幂等派发、账号权限复核；
   默认停用，由负责人显式启用。超过30分钟的来源停止派发并发出本地补采提示。
   计划绑定不可变数据集，不宣称自动刷新外部数据或真实持续掉锁监控。
7. **本地可移植导出**：审批绑定数据集及格式，一次性消费。
   可导出 ZIP 内 UTF-8 BOM CSV：固定19列主表、候选人流程、面试明细、面评明细、岗位统计及口径。
   Excel 可直接打开 CSV；这不是新生成的 `.xlsx`。既有核验 `.xlsx` 仍作为历史导出保留。
8. **InstSci MCP**：真实 stdio initialize/list_tools/call_tool；只允许 search_papers/get_paper_metadata；
   不允许下载 PDF、切换机构、任意执行命令。服务启动路径由管理员本地配置。
   上游把失败合并为空结果时标注 empty_or_provider_unavailable，不假称没有相关论文。
9. **内部知识检索**：加密存储、部门授权、中文双字/英文词检索、原文字符区间引用；
   不外传、不执行资料中的指令。这是本地词项检索，不是向量 RAG 或自学习排序。
10. **指定窗口录制**：浏览器原生选择器由用户选择招聘标签页/窗口，不录整个桌面；
    保存 WebM 到 `data/recordings/browser-selected/`，权限0600；
    文件命名 `YYYYMMDD-HHMMSS-招聘操作录频-随机ID.webm`。单段最多2分钟/19MB。
    需要用户选择来源并检查预览；服务器不能证明用户选中的一定是招聘页面。

## 使用

运行 `./install.sh` 后运行 `./start.command`，本机打开 `http://127.0.0.1:8765/console`。
账号与本机随机访问密钥在 `data/platform/local-access.txt`，不要转发该文件。
新安装不带真实简历、账号、Cookie、token、录屏或数据库。

在“北森只读连接”中：
- “读取当前岗位”：只更新该区域显示的岗位清单。
- “采集申请并核对入库”：生成只有当前申请存量的新数据集，面试率未知。
- “采集申请与面试并审计”：依次采集岗位、申请和面试；来源缺口在结果中保留。
- 页面的验证码、登录及浏览器用户接管必须由用户完成；失败不会绕路继续。

在“人工审批”中选择 `report.export` 和 CSV 台账包，发起、批准、执行后下载。
导出数据不会发布到如流。旧 Excel 链接不是刚刚采集数据的 Excel，不可混淆。

可选 MCP 安装：

```sh
.venv/bin/python -m pip install -r requirements-mcp.txt
# 另外安装经企业审核的 InstSci 源码包/版本。
# 同一虚拟环境中的 instsci-mcp 会自动发现；否则在 .env 设置绝对路径。
```

不要把企业密钥写在 URL、文档或消息中。不要沿用曾经发送到聊天里的 token。

## 模型

默认统计、采集、模板、巡检和知识检索不调用大模型。
只有 `analyst` 使用 `.env` 中批准网关的 `LLM_MODEL`，需显式允许数据出站。
配置名 `gpt-5.6-sol` 不证明网关实际后端模型身份，也不代表本次业务运行调用过该模型。
InstSci MCP 不是 LLM，也不是自动下载授权。
