# TalentPilot v0.5：Comate 方案融合与验收

日期：2026-09-21。此文是 v0.5 的能力基准；旧交付文档保留作历史记录。

## 交付定位

可安装的本地 Agent 应用，包含后台执行器、网页控制台、共享状态、专用模块、权限与审批。
不是只有 Skill，也不是所有外部接口均已完成的全自主招聘机器人。
自主完成已经接通的只读业务链；招聘写操作与数据导出保持人工在环。

## 从 Comate 吸收了什么

分析材料：用户提供的 talentpilot-agent_full.zip。只读审查源码，没有执行附带脚本或导入其人工数据。
本版重新实现其有效设计，没有将其演示结果当作真实北森结果。

| 设计 | 本版落地 | 关键修正 |
|---|---|---|
| 依赖任务编排 | live_runs.py 的六步持久化 DAG | 上游失败绝不继续；检查点加密；崩溃需显式恢复 |
| 简历多版本与去重 | resume_registry.py，本地解析登记 API | SHA256+文本哈希；事务版本分配；冲突不自动合并 |
| 重新申请冷却期 | 普通30/技术60/高端90/二次180天，三次特批 | 必须有明确淘汰时间与解锁事实；永不直接提交北森 |
| 结构化评分卡 | scorecards 专用模块，负责人可见 | 按同一场面试分组，各维度单独分母；缺失不是零 |
| 全链路结果报告 | 自动创建绑定本次数据集的导出审批 | 审批不可变、限时、一次消费；缺口独立披露 |

未采用的危险实现：
- Comate classify_result 先按子串匹配“通过/推荐”，会误判“不通过/不推荐”。
  本版坚持已核实的精确枚举，不认识的结论归未知，不猜测。
- talentpool.push 只追加本地事件，不构成北森推进；本版外部适配器未配置时明确 blocked。
- 不使用姓名+学校推断身份，不保存明文联系方式作为合并索引。
- 不将 Offer 类型或入职存量算成已发送 Offer，不混合不同轮次评分。

## 一次提交后的执行过程

```text
岗位列表 -> 当前申请列表 -> 全部时间面试列表 -> ID/覆盖校验及入库
        -> analytics / insights / locks / loads -> 本地导出审批
```

- POST /api/platform/live-runs，request_key 防重复。
- GET /api/platform/live-runs，返回每步状态、依赖、完成步骤、数据集和审批 ID。
- POST /api/platform/live-runs/{id}/resume，管理员检查后恢复。
- POST /api/platform/live-runs/{id}/cancel，终止后续步骤；在途只读请求完成后退出。
- 采集超时有上限；单个步骤租约400秒；最多12次步骤完成/失败计数。
- 断点超过30分钟重新采集。服务重启、失去浏览器控制时不会自动抢回控制权。
- 只有启用且拥有全部门权限的本机管理员能启动实时采集；每步重新校验权限。
- 未配置长期实时采集计划；旧巡检计划只检查指定快照，不冒充实时监控。

## 使用

1. 解压，执行 install.sh，再执行 start.command；需要 Python3.10+ 和依赖安装网络。
2. 用 data/platform/local-access.txt 的本机账号/密钥登录 http://127.0.0.1:8765/console。
3. 在 Ego 中自行登录北森，再点击“启动北森采集与审计”。
4. 完成后点击“查看本次台账”；审查范围和未知项。
5. 在“人工审批”核对 report.export 参数，批准后点击“执行已批准动作”下载 CSV 包。
6. 新增本地简历功能要求放入 data/imports，并指定当前数据集中已存在的候选人ID。
   支持文本型 PDF、DOCX、TXT、MD；空白或扫描件需单独 OCR，不假装解析成功。
7. 录屏仍需用户选择招聘窗口。单段最长2分钟，保存到 data/recordings/browser-selected，
   文件名为“日期时间-招聘操作录频-唯一ID.webm”。没有声称本轮录制了完整招聘任务视频。

源码包不带用户数据、数据库、简历、录屏、密码、token、会话或内网网关密钥。
另一台机器需要自己的授权账号与浏览器会话，不能安装后继承本机权限。

## 模型、接口与边界

默认只读链和统计不需要大模型。可选 analyst 的配置路由为 gpt-5.6-sol，
真实网关身份与调用效果未验收；默认禁止出网。这里只能解释匿名数值，不替代招聘决策。
北森连接使用 Ego 授权页面和页面当次请求响应，不重放旧签名，不绕过风控。
InstSci MCP 仍仅允许检索/元数据；下载、BOSS、如流写文档、北森推荐、上传、超限排期适配器未完成。
RAG 目前是带来源的本地词法检索，不是向量 RAG。

不能宣称已完成原PRD的全部功能。后续真实接入仍需要：
- 北森面评/历史筛选/锁/Offer详情的可核验数据来源和权限。
- 精确候选人、目标岗位、阶段、状态指纹与明确审批后的写入和回读适配器。
- 如流目标文档、本人登录绑定及授权接口；BOSS企业授权接口及配额契约。
- 海外独立部署、合规审查、企业SSO/KMS、跨系统删除和生产监控。

本版导出是可用 Excel 打开的 CSV 台账包，不是新的原生 xlsx。
保留固定19列主表；每个申请一行；更多证据放明细表。旧 Excel 下载仍明确标为历史文件。
